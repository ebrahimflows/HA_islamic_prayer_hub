# Security

Prayer Hub is a community Home Assistant custom integration.

## Before reporting an issue

Do not post:

- Home Assistant access tokens
- webhook/callback tokens
- private domain names
- exact local IP addresses unless necessary
- Fully Kiosk passwords
- device IDs unless they are essential to reproduce the problem

The Prayer Hub finish callback contains a randomly generated token created locally during setup. Do not publish that token.

For a public repository, use GitHub's private vulnerability reporting feature if enabled. Otherwise contact the repository maintainer privately.
