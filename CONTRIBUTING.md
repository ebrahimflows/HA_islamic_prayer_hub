# Contributing

Prayer Hub is shared as an **as-is community project** and is not actively maintained on a fixed schedule.

Forks, fixes and pull requests are welcome, but there is no guaranteed review or response time.

If you want to contribute:

1. Fork the repository.
2. Create a focused feature or fix branch.
3. Test the change on a non-critical Home Assistant instance where possible.
4. Ensure the HACS and Hassfest validation workflows pass.
5. Open a pull request explaining what changed and how it was tested.

Please never commit personal Home Assistant URLs, callback tokens, credentials, passwords, device IDs or other private configuration.

If the original repository becomes inactive, you are welcome to maintain your own fork.
