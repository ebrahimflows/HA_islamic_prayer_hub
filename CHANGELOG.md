# Changelog

## 2.3.2

Stable community release shared as-is. No regular maintenance or release schedule is promised.

### Features

- London Unified Prayer Times (LUPT) source detection
- Current, next, countdown and Islamic date sensors
- Automatic prayer triggering from LUPT state changes
- LG/webOS-compatible TV mute and restore using a media-player entity
- Pulse only selected lights that are already on
- Preserve brightness and the active light colour mode
- Wake a Fully Kiosk tablet
- Five prayer-specific display themes
- Local Qur'an reminder and Qur'anic du'a rotation
- Full-screen landscape YouTube azaan playback
- Separate Fajr azaan video support
- Automatic Europe/London / Home Assistant timezone conversion
- Private local callback to restore TV audio when playback ends
